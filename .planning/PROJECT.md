# Freight TMS

## What This Is

Система управления грузоперевозками для парка 100+ водителей и 200+ фур на международных маршрутах (CN↔KZ, KZ↔RU, Центральная Азия, Турция, Грузия). Водители работают через Telegram-бот на телефоне, диспетчеры и директор — через веб-панель.

## Core Value

Диспетчер в любой момент знает где каждый борт, что везёт, сколько потратил — и может назначить новый рейс до возврата машины.

### Active

**Водители (Telegram-бот):**
- [x] Водитель регистрируется и привязывает борт
- [x] Водитель открывает рейс (маршрут, груз, накладная/CMR)
- [x] Водитель фиксирует расходы: топливо (фото чека + литры + одометр), суточные, штрафы, ремонт/запчасти
- [ ] Водитель делится геолокацией по кнопке каждые N часов
- [ ] Водитель закрывает рейс (финальный одометр, документы)

**Диспетчер (веб-панель):**
- [ ] Список всех бортов со статусом (свободен / в рейсе / местоположение)
- [ ] Назначить рейс борту (маршрут, груз, клиент, документы)
- [ ] История рейсов по борту/водителю
- [ ] Просмотр расходов по рейсу

**Директор (веб-панель):**
- [ ] Карта с позициями бортов
- [ ] Отчёт по расходам: топливо, суточные, штрафы — по бортам/периодам
- [ ] Алерты при аномальном расходе топлива (>10% нормы)
- [ ] Аналитика: средний расход по бортам, история нарушений

- Интеграция с 1С/ERP — V2
- Финансовый модуль (выставление счетов клиентам) — V2
- Мультиязычность — интерфейс на русском

## Context

- Текущий бот (`/Users/osmagulov/бот диспетчер логист`) реализует контроль топлива — будет перенесён и расширен в этом проекте
- Водители привыкли к Telegram, переучивать не нужно

- Маршруты международные: важны таможенные документы (CMR, накладная, договор)
- Текущий инструмент: WhatsApp/Telegram — всё в голове и переписке

## Constraints

- **Tech**: Python ecosystem (FastAPI + python-telegram-bot) — команда знает Python
- **Database**: PostgreSQL — масштаб 100+ водителей требует реляционной БД
- **Deployment**: Railway — уже используется для текущего бота
- **Scale**: 100+ водителей, 200+ фур — архитектура должна выдерживать одновременные запросы
